🗄️ Enterprise MySQL 8.4 LTS Engine Database
  • Strict ACID transactions with InnoDB and utf8mb4_0900_ai_ci collation.
  • Biometrics: Native JSON 128-float arrays with SHA-256 integrity hashes.
  • Composite indexes: idx_att_emp_ts, idx_att_ts_status, idx_emp_dept_status.
  • Resilient dual-dialect router with automatic zero-downtime fallback to SQLite.
🔐 Zero-Plaintext Security Architecture Hardened
  • Usernames indexed as SHA-256 hashes (zero plaintext leaks in DB or query logs).
  • Passwords hashed with Bcrypt (cost factor 12).
  • Immediate JWT token revocation via in-memory and database blacklist.
  • Strictly admin-governed credential resets via /api/admin/users.
👥 Admin User Governance Console Console
  • Manage system roles: ADMIN, USER, HR, EMPLOYEE, DEVICE.
  • One-click secure credential generation and instant password resets.
  • Self-deletion protection prevents administrator lockouts.
  • Full security audit logging for all account modifications.
🚀 DSA LRU Caching & Single-Command Run Performance
  • Custom \(O(1)\) Doubly-Linked-List LRU cache with TTL eviction.
  • Prefix Search Trie for sub-millisecond employee and department lookups.
  • Server-Sent Events (/api/sync/events) for atomic cache invalidation.
  • Single-command run: npm start auto-starts local MySQL daemon.
